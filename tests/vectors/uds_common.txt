# Requests both UDS servers must answer the same way, run in order from the default session
# after the SecurityAccess boot delay. Format:  request | start of the response | what it shows
#
#   - tests/renode/test_uds_common.py replays this against the production command layer
#   - the iso14229 server replays it in its on-chip self-test (bl_uds_vectors.h, made from this
#     file by scripts/gen_uds_vectors.py; tests/test_uds_vectors_sync.py keeps the two in step)
#
# Only the leading bytes of a response are compared, so timing parameters and seeds are free.
# Keep the list stateless towards SecurityAccess: no wrong keys here, they start a delay.

22 F1 86       | 62 F1 86 01 | active session reads back as default
